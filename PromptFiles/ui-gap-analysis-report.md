# AgentBell UI 重设计 — 差异分析报告

> 基于当前 UI 截图（now1.png / now2.png）与目标设计文档（agentbell-ui-redesign-target.md）的逐项对照分析。
> 生成日期：2026-06-09

---

## 一、总体评估

当前实现已经完成了大部分核心 UI 重设计工作。主要组件（托盘菜单、最近事件窗口、Toast、托盘图标）均已从系统默认替换为自定义深色 Win32 GDI 实现。剩余差异集中在 **视觉细节打磨** 和 **后端功能补全** 两个层面。

## 四、差异优先级汇总

### P0 — 必须修复（影响核心体验）

1. **Event Store 持久化** — 当前 daemon 重启后所有事件丢失，最近事件窗口变空。需要实现 JSON 文件持久化 + 查询接口。
2. **托盘菜单 Header 缺少橙色 `>_` 图标** — 目标设计的标志性视觉元素缺失。

### P1 — 应该修复（视觉一致性）

3. **托盘图标外形** — 目标为橙色圆角方块，当前为深色圆形。任务栏辨识度不足。
4. **卡片 hover 效果** — 目标要求 hover 时边框变橙色，需确认是否实现。
5. **最近事件窗口空状态** — 需确认是否已实现空状态 UI。
6. **Toast 项目标签 (Project Pill)** — 需确认 Toast 中是否显示项目 pill。

### P2 — 可以延后（功能完善）

7. **卡片点击交互** — 当前为 no-op，目标要求展开详情或复制信息。
8. **"设置" / "关于 AgentBell" 菜单项** — 当前禁用/无 handler。
9. **托盘图标多尺寸** — 当前仅 16x16，缺少 24/32/48/256px。
10. **Toast 去重窗口** — 3s → 5s 小调整。
11. **Toast 动画** — 滑入/滑出动画需确认。

## 五、已完成项（无需修改）

- 深色 Claude Theme 色板统一
- 托盘菜单自定义 Popup（非系统 QMenu）
- 最近事件窗口自定义 Popup（非 QMessageBox）
- 事件卡片三行结构（状态+时间 / session·event / 描述）
- 状态圆点颜色映射（橙/蓝/绿/红/灰）
- Toast 左侧 `>_` 图标 + 不同事件类型颜色
- Toast 展开/收起功能
- Toast 自动消失 8 秒
- Toast 堆叠 + 去重
- 托盘图标默认态/未读态/静音态
- 托盘菜单 badge 显示
- 所有 UI 使用纯 Win32 GDI 绘制，无外部依赖
